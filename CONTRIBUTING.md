# Contribuciones

1. Hacer un fork del repositorio.
2. Crear una rama para la contribución.
3. Realizar los cambios y comprobar que estén dentro del alcance del proyecto.
4. Abrir un Pull Request con una descripción breve de los cambios.

No incluir shapefiles pesados, ortofotos, bases geográficas, datos institucionales no autorizados, credenciales ni tokens. Los archivos geográficos pesados deben permanecer en local; no usar Git LFS para incorporarlos.

El código fuente del procesamiento está pendiente de incorporación. Las contribuciones deben respetar este estado y no presentar el repositorio como completamente reproducible.
